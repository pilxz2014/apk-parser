# APK 工具箱 · 使用说明（接收方）

> 这是随发行包一起发出的说明书。打包脚本会把本文件复制成 `使用说明.txt` 放进发行目录
> （`package_win.py` / `package_mac.py` 里的 `copy_readme()`），所以**只维护这一份**。

这是一个 Windows 绿色小工具（Android 开发/测试用）：**双击就能跑，不用装 Python、不用联网、
不改系统设置**。主要能干四件事——看 APK 信息、启动任意 Activity/Service、录屏截图抓日志、装 APK。

---

## 1. 怎么装（1 分钟）

1. 把收到的 **`APKConsole-win.zip` 完整解压**到一个固定目录，例如 `D:\APKConsole`
   - **必须整个文件夹一起解压**：`APKConsole.exe` 和 `_internal` 文件夹是一套，缺一不可；
     只把 exe 拖出来会打不开（报错找不到模块）
   - 别放 `C:\Program Files`：程序把产物写在**自己所在目录**，那里需要管理员权限
2. **双击 `APKConsole.exe`**
3. 首次运行 Windows 可能弹「**Windows 已保护你的电脑**」→ 点「更多信息」→「仍要运行」
   （程序没有商业代码签名，这是未签名程序的常规提示，不是病毒）
4. 浏览器会自动打开主控台 **`http://127.0.0.1:5170`**，同时右下角通知区出现**绿色「APK」图标**
   - **看不到图标？点通知区左边的 `^`（向上箭头）** —— Windows 10 默认把新图标收进「溢出区」，
     把它拖到任务栏上就能固定出来
5. 以后再双击 exe：服务已经在跑 → **不会重复启动**，只是把页面打开（单例）

## 2. 怎么退出

- 托盘图标**右键**：`运行中 · http://127.0.0.1:5170` / 打开主控台 / 重启服务 / 启动服务 /
  停止服务 / 退出
- **关掉浏览器 ≠ 退出**，服务还在后台跑（图标是绿的）；要彻底停：右键 →「退出」

## 3. 怎么用（主控台左侧导航）

分两个一级域，按「要不要插手机」划分：

**本机 · APK**（不插手机也能用）：解析 APK、查看签名、双包对比、体积构成、批量解析、提取图标
- 选文件三种方式：**把 apk 拖进页面** / 点「浏览…」（服务端弹原生文件框）/ 直接粘路径

**设备 · 应用 / 启动器 / 捕获 / 安装 / 文件**（需要连手机）：应用列表与详情、免 root 看已装应用签名、
导出 APK、强制停止、清数据、卸载；启动组件 / 发广播；截图 / 录屏 / 实时镜像 / 日志；安装预检与安装

界面上的每个动作都会显示**将要在手机上执行的真实命令**，可以一键复制走。

## 4. 连手机（可选；只用本机功能可以跳过）

1. 装 Android SDK 的 **platform-tools**（里面有 `adb`），让它满足其一：
   `adb` 在 PATH 里 / 设环境变量 `ANDROID_HOME` 指向 SDK 目录 / 放到常见的
   `D:\SDK`、`C:\Users\<你>\AppData\Local\Android\Sdk`
2. 手机上：设置 → 关于手机 → 连点「版本号」7 次 → 回到设置打开「**USB 调试**」
3. USB 连电脑，手机弹「允许 USB 调试吗」→ **允许**
4. 主控台「设备 · 应用」里能看到设备就成功了；路径不对可在「系统 · 设置」里手动指定 adb

> 没装 adb 也不影响本机 APK 解析/签名/对比这些功能 —— 设备域会红字告诉你缺什么、去哪装。

可选增强（缺了只影响对应功能）：`aapt2` / `apksigner`（签名交叉校验）、`scrcpy`（实时镜像）、
`ffmpeg`（录屏转 GIF）。

## 5. 数据放在哪 / 怎么卸载

| 内容 | 位置 |
|---|---|
| 产物（截图、录屏、导出的 apk、提取的图标） | exe 同级的 `output\` |
| 日志 | exe 同级的 `logs\` |
| 缓存 | exe 同级的 `cache\` |
| 配置（端口、外部工具路径等） | `C:\Users\<你>\.apk-parser\config.json` |

**卸载**：托盘右键「退出」→ 删掉整个文件夹 → （可选）删掉 `%USERPROFILE%\.apk-parser`。不写注册表、
不留服务、不留开机自启。

## 6. 安全说明

- 服务**只监听 `127.0.0.1`**（本机回环），局域网和外网都访问不到，别人连不上你的主控台
- 每次启动生成随机 token，**其他网页无法调用**本机接口
- 全程不申请 root、不改 .apk 的默认打开方式

## 7. 常见问题

| 现象 | 怎么办 |
|---|---|
| 双击后「好像只是后台启动了一下」，没看到界面 | 看通知区 `^` 里有没有绿色图标；再双击一次 exe 会打开页面 |
| 页面打不开 / 无响应 | 托盘右键 →「重启服务」 |
| 端口 5170 被占用 | 会自动顺延（最多 20 个），真实地址看托盘 tooltip 或启动通知 |
| 提示找不到 adb | 见第 4 节；或在「系统 · 设置」里手动指定 adb 路径 |
| Defender / 杀软拦截或误报 | 加信任白名单（未签名程序的常见误报，不是病毒） |
| 托盘图标被折叠了 | 通知区 `^` → 把「APK」拖到任务栏固定 |

## 8. 已知限制（发行包）

- **发行包里没有 `.apk` 右键菜单 / 双击安装**：这套功能在源码安装版里靠根目录的
  `apk-*.cmd` 薄壳脚本 + 右键注册表项实现，绿色包里没有这些脚本。
  → 请直接用主控台，功能一样全（把 apk 拖进页面即可；安装走「设备 · 安装」）。
- **只有 Windows 版**：macOS 需要在 mac 机器上执行 `package_mac.py` 自行构建，产物是
  `APKConsole.app`（本机无法交叉编译 Windows → mac）。
- 主控台界面语言为中文，界面上的时间/体积等按本机区域设置显示。
